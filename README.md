# AK Cricket Match Center & Analytics 🏏

An AI-assisted cricket scoring and match analytics application designed to bring the experience of managing a cricket match into a browser-based platform.

The project combines cricket rules, AI-assisted development, interactive UI design, live scoring, and match analytics.

## About the Project

AK Cricket Match Center & Analytics is a browser-based application designed to manage cricket matches from setup to scorecard analysis.

The goal was to build an interactive platform where users can set up teams, record ball-by-ball scores, manage wickets and extras, and explore match statistics through visual analytics.

Rather than writing the application code manually, I used AI tools throughout the development process, from planning and UI design to application generation and refinement.

## Key Features

- **Match Setup:** Configure matches, select international teams, and manage player squads.
- **Live Scoring:** Record runs, wickets, overs, and ball-by-ball match events.
- **Extras Management:** Handle wides, no-balls, byes, and leg-byes.
- **Wicket Management:** Record different modes of dismissal.
- **Scorecards:** View batting and bowling performance.
- **Match Statistics:** Track partnerships, fall of wickets, and run rates.
- **Visual Analytics:** Explore match data through run-rate trends, worm charts, and wagon wheels.
- **Undo Functionality:** Reverse scoring actions when required.
- **Browser-Based Storage:** Retain match information using local browser storage.

## AI Tools & Development Workflow

This project was developed using a combination of AI tools, with each tool serving a different purpose.

| Tool | How I Used It |
|---|---|
| ChatGPT | Brainstorming, project planning, cricket scoring logic, feature requirements, and prompt creation and refinement. |
| Google Stitch | Designing the application's user interface, layouts, and visual direction. |
| Google AI Studio | Turning the design and detailed prompts into a functional application, generating code, implementing features, and refining the application. |
| GitHub | Version control and hosting the project source code. |

### Development Process

1. **Idea & Planning:** Defined the project concept, features, and cricket scoring requirements with ChatGPT.
2. **UI Design:** Used Google Stitch to create the visual design and application layout.
3. **AI-Assisted Development:** Transferred the design into Google AI Studio and used detailed prompts to generate the application.
4. **Feature Implementation:** Refined the application through additional prompts covering scoring rules, extras, dismissals, scorecards, analytics, and browser storage.
5. **Source Code Management:** Pushed the generated project source code to GitHub.

## How to Run the Project Locally

You can download the source code and run the application on your computer.

### Prerequisites

- [Node.js](https://nodejs.org/)
- npm
- [Git](https://git-scm.com/)

### Steps

**1. Clone the repository**

```bash
git clone https://github.com/Akanchibail/ak-cricket-match-center.git
```

**2. Open the project folder**

```bash
cd ak-cricket-match-center
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the application**

```bash
npm run dev
```

**5. Open it in your browser**

After starting the development server, open the local URL displayed in your terminal.

The application will typically be available at:

```text
http://localhost:5173
```
